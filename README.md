# 《搜尋戀曲 ～青葉學園網站研究社～》

> 純前端、桌機瀏覽器遊玩的青春校園戀愛養成遊戲，以 **SEO／AEO／GEO** 為主題，結合六週排程養成、委託支線、小遊戲與知識卡圖鑑收集。

## 遊戲特色

- **三位女主角 × 三大搜尋領域**：
  - **白鷺 凜（SEO）**：傳統搜尋、爬取與索引、網站速度、規範與結構。
  - **夏川 晴（AEO）**：答案引擎、搜尋意圖、問題型標題、結論先說。
  - **星野 未來（GEO）**：生成式搜尋、原創資料與資訊增益、來源引用、實體一致性。
- **六週養成循環**：每週經歷「週一主線＋實戰小遊戲 → 平日 4 格排程（含主題 ×1.5 加成、體力／壓力與隨機小插曲）→ 放學後委託公佈欄（10 件支線）→ 週末約會（3 階段＋普通相處）→ 週日評測報告」，第 6 週結束迎來「搜尋祭」與 **7 種結局**。
- **三種互動小遊戲引擎**（主線 6 個＋支線 10 個，共 16 個）：
  - `quiz`：多題實務選擇題與即時解說。
  - `spot`：程式碼／內容找錯（多目標、限錯 3 次）。
  - `serp`：即時 Google 搜尋結果預覽與標題／描述片段評分。
- **收集與重玩系統**：38 張知識卡圖鑑（含 7 張只能從支線取得的進階卡）（依據 2026 年實務撰寫）、10 張事件 CG 回憶相簿、7 種結局達成清單、小遊戲練習模式。
- **WebP 美術與合成音效**：71 項 WebP 美術資產（角色立繪表情、場景背景、事件 CG、活動插圖與 Logo；缺圖時才退回程式繪製的 SVG 備援），搭配眨眼、說話與呼吸動畫、15 種時段／天氣背景與粒子特效，以及 Web Audio 合成音效與 3 首循環 BGM。

## 操作方式（建議視窗寬度 ≥ 1024px）

| 按鍵 / 操作 | 功能 |
|---|---|
| `滑鼠點擊` / `Space` / `Enter` | 推進對話（打字中則瞬間顯示完整行） |
| `1`～`9` | 快速選擇劇情選項 |
| `Ctrl`（長按） | 快轉文字（預設僅快轉已讀對話） |
| `A` | 切換自動播放 |
| `L` | 開關對話紀錄（Backlog） |
| `H` | 隱藏／顯示介面 |
| `Esc` | 開關遊戲選單（存檔／讀檔／設定／圖鑑） |

## 開發指令

```bash
# 安裝相依套件
npm install

# 本機開發伺服器
npm run dev

# 型別檢查
npm run typecheck

# 執行單元、劇本 lint、時長與平衡模擬測試（Vitest）
npm test

# 正式建置（輸出至 dist/）
npm run build

# 預覽正式建置
npm run preview

# Playwright 全程通關與截圖 E2E 測試（需本機 Chrome 或 Edge）
npm run e2e
```

> Windows PowerShell 若封鎖 `npm.ps1`，請改用 `npm.cmd`／`npx.cmd`。

## 部署到 Vercel

專案已內建 [vercel.json](./vercel.json) 靜態建置設定：

1. 前往 Vercel Dashboard，匯入 GitHub 儲存庫 `lu7766lu7766/seo-journey`。
2. Framework Preset 選擇 **Vite**，Build Command 為 `npm run build`，Output Directory 為 `dist`（已由 `vercel.json` 預設）。
3. 點擊 Deploy；之後每次推送到 `main` 分支即會自動部署。
4. 或於本機登入 Vercel CLI 後執行 `vercel --prod` 部署。
